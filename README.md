# 灵感收纳箱 · Mellow

快速记录碎片想法，再完成分类收纳与表达整理。

> 本仓库为个人产品的脱敏公开展示版，保留原核心界面与交互。私人空间码、初始个人内容、云端配置和旧提交历史未纳入。数据只保存于当前浏览器。

## 为什么做

记录想法时，笔记工具通常要求先决定放在哪篇笔记、用什么格式；聊天记录虽然输入方便，却需要后续筛选归档。
Mellow 将输入和整理分开：先写下内容，再由分类建议与用户确认完成收纳。

它是想法捕捉和临时整理工具，不替代完整知识库。

## 核心能力

- 快速输入文字灵感，支持手动选择收纳单元。
- 新建、编辑、搜索、置顶收纳单元，以及复制内容。
- 未确定归处的内容保留在待分类池。
- 按日期回顾灵感历史，搜索内容。
- AI 分类建议：提供候选单元，用户确认或调整。
- “说人话”：辅助整理表达；“再想下”：提供更多思考角度。

真实 AI 能力依赖服务端模型配置。未配置密钥时可体验手动记录与收纳；分类接口失败时会使用本地相似度候选，它不是 LLM 输出。润色与扩展不保证在无密钥时可用。

## 设计取舍

**先记录，后确认。** 输入时减少结构决策，归类时保留人工控制。

**按单元聚合。** 标题和描述用于界定收纳范围，便于回顾与复制到其他知识工具。

**AI 辅助，不替用户决策。** 分类和生成内容可能错误，需要人工核对。

## 本地运行

需要 Node.js 22 或更新版本。

```bash
npm install
npm run dev
```

打开 http://localhost:3000，选择创建空白空间或示例空间。展示版示例空间也不预置私人内容，请先新建收纳单元。

如需真实 AI，在项目根目录创建被 Git 忽略的 `.env`：

```dotenv
ZHIPU_API_KEY=
QWEN_API_KEY=
```

密钥只保存在服务端，不得放进 `VITE_*` 变量。使用 AI 会把相关文字发送到所配置的模型服务。

```bash
npm run check
npm run build
```

`npm run preview` 只预览静态前端，不提供 AI 接口；完整本地体验使用 `npm run dev`。

## 技术与源码

React、TypeScript、Vite、Tailwind CSS、Express；UI 组件位于 `components/ui`。

- `src/App.tsx`：输入、分类确认、待分类池、单元管理和历史界面。
- `src/lib/storage.ts`：数据结构与本地持久化。
- `src/services/geminiService.ts`：分类、润色、扩展请求及分类降级逻辑；文件名沿用早期版本。
- `server.ts`：本地前端服务与模型请求代理。
- `src/components`：产品说明。

云端访问在本公开版中固定关闭，不能通过填写 Supabase 变量连接作者数据库。原私有开发版保持不变。
